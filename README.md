# 📊 Data Preprocessing and Exploratory Data Analysis Projects

## 📌 Overview

This repository contains multiple data preprocessing and exploratory data analysis (EDA) projects performed on real-world datasets from different domains. The primary objective of these projects is to understand raw datasets, clean inconsistent data, apply preprocessing techniques, and prepare the data for future machine learning applications.

The work included in this repository demonstrates practical implementation of:

* Data Cleaning
* Missing Value Treatment
* Outlier Detection
* Feature Engineering
* Encoding Techniques
* Feature Scaling
* Data Transformation
* Exploratory Data Analysis
* Statistical Visualization

These projects were developed using Python and common data science libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

---

# 🏭 Project 1: Smart Manufacturing Dataset Analysis

## 🎯 Objective

To preprocess and analyze manufacturing data in order to understand operational patterns, production behavior, and energy consumption trends.

## ⚙️ Work Performed

* Handled missing values and duplicate records
* Applied outlier detection using the IQR method
* Performed log transformation using `log1p()` on skewed numerical features
* Encoded categorical variables
* Applied feature scaling techniques
* Conducted correlation analysis and distribution analysis
* Generated visualizations for production and energy-related metrics

## 📚 Key Learning Outcomes

* Understanding preprocessing techniques for industrial datasets
* Handling skewed numerical distributions
* Building preprocessing workflows for predictive analytics
