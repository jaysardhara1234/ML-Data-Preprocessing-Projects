# 🏭 Smart Manufacturing Dataset Analysis & Data Preprocessing

## 📌 Project Summary

This project focuses on performing Data Cleaning, Data Preprocessing, and Exploratory Data Analysis (EDA) on a Smart Manufacturing dataset using Python and various data science libraries.

The primary objective of this analysis was to understand industrial manufacturing data, analyze operational and production-related patterns, and prepare the dataset for future machine learning and predictive analytics applications.

The dataset contained both numerical and categorical industrial features related to manufacturing operations, production metrics, equipment-related information, and energy consumption patterns. Multiple preprocessing techniques were applied to improve data quality, reduce inconsistencies, and transform the dataset into a machine-learning-ready format.

---

## ⚙️ Work Performed

The following preprocessing and analytical tasks were performed during the project:

- Dataset loading and inspection
- Understanding manufacturing-related features
- Missing value handling
- Duplicate record removal
- Exploratory Data Analysis (EDA)
- Outlier detection and treatment
- Log transformation using `log1p()`
- Categorical feature encoding
- Feature scaling
- Correlation analysis

- Energy consumption analysis
- Visualization of industrial and production trends

Several statistical and visualization techniques were used to better understand manufacturing patterns and operational behavior within the dataset.

## 📊 Exploratory Data Analysis (EDA)

EDA was performed to gain insights into industrial operations and manufacturing-related patterns.

The analysis helped in:
- Understanding production-related distributions
- Detecting skewed numerical features
- Identifying operational trends
- Understanding energy consumption behavior
- Detecting outliers and anomalies
- Identifying correlations between manufacturing-related features

Visualization techniques such as histograms, boxplots, heatmaps, distribution plots, and correlation analysis were used during the analysis process.

## 🧹 Data Preprocessing Techniques Used

The preprocessing phase focused on improving industrial dataset quality and preparing the data for machine learning workflows.

### ✔ Missing Value Handling
Missing values were identified and treated appropriately to improve dataset consistency and analytical reliability.

### ✔ Duplicate Removal
Duplicate records were removed to maintain data accuracy and reduce redundancy.

### ✔ Outlier Detection
Outliers were detected using statistical and visualization-based techniques such as:
- Boxplots
- IQR Method

### ✔ Log Transformation
Log transformation using `log1p()` was applied on skewed numerical features to reduce skewness and improve feature distributions.

### ✔ Encoding Techniques
Categorical manufacturing-related features were converted into numerical format using encoding methods such as:
- Label Encoding
- One-Hot Encoding

### ✔ Feature Scaling
Feature scaling was applied to normalize numerical feature ranges and improve consistency for future machine learning models.

Scaling methods may include:
- StandardScaler
- MinMaxScaler
